# 【AIプロンプト用仕様書】ECサイト演習プログラム仕様書 (exShop)

本書は、AI（ChatGPT / Claude / Gemini等）に渡して**Django版と同等のECサイトを「Flask」または「Java Servlet / JSP」で再現・実装させるための完全プロンプト仕様書**です。

---

## 1. プロジェクト基本要件

| 項目 | 内容 |
|---|---|
| **システム名称** | exShop (セレクトECサイト) |
| **開発目的** | クラウド（AWS EC2 / App Runner / ECS 等）へのデプロイ演習およびWebアプリケーション設計・実装演習 |
| **UIデザイン** | Bootstrap 5.3 + Bootstrap Icons (レスポンシブWebデザイン) |
| **主要対象言語** | Python (Flask / SQLAlchemy) または Java (Jakarta EE Servlet / JSP / JDBC or JPA) |

---

## 2. 機能一覧要件

1. **ユーザー認証・アカウント管理**
   - 新規会員登録（ユーザー名、姓名、メールアドレス、パスワード）
   - ログイン / ログアウト（セッション管理）
   - マイページ（ユーザー情報確認、最近の注文履歴、お気に入り一覧プレビュー）
2. **管理者機能**
   - 一般スタッフ・管理者のみが利用可能な管理画面
   - 商品の新規登録・情報編集・削除機能
3. **商品一覧・検索・絞り込み**
   - 商品一覧カード表示（画像、商品名、タグバッジ、価格、在庫状況、お気に入りボタン、カート投入ボタン）
   - キーワード検索（商品名および商品説明に対する部分一致検索）
   - タグ絞り込み（タグ一覧を表示し、指定タグに紐づく商品のみを抽出）
   - 並び替えソート（新着順、価格の安い順、価格の高い順）
   - ページネーション（1ページあたり12件表示）
4. **商品詳細表示**
   - パンくずリスト
   - 商品画像（拡大表示）、商品名、タグ、税込価格、在庫残数、商品説明文
   - 数量指定カート追加フォーム
   - お気に入り登録・解除トグル
   - 同一タグを持つ「関連商品」のレコメンド表示
5. **画像フォールバック仕様 (重要)**
   - 商品画像が登録されていない、または画像ファイルが存在しない場合は、必ずデフォルト画像（`no-image.png`）を代替表示すること。
6. **カート機能**
   - セッションベースのカート管理
   - カート一覧表示（商品画像、商品名、単価、数量変更セレクト、小計金額、削除ボタン）
   - 合計金額の自動計算（税込表示、配送料無料表示）
   - カートが空の場合のガイダンス表示
7. **購入・注文処理**
   - 注文手続き画面（お届け先氏名、メールアドレス、電話番号、郵便番号、住所、支払方法選択）
   - 注文確定処理（DBトランザクション処理、在庫数減算、カートクリア、注文番号自動生成: `ORD-XXXXXX`）
   - 注文完了画面（サンクスページ）
8. **購入履歴**
   - ログインユーザー専用の過去注文一覧
   - 注文詳細画面（お届け先、支払方法、購入明細テーブル、購入時単価・数量・小計）
9. **お気に入り (Wishlist) 機能**
   - 商品一覧・詳細ページからワンクリックで追加/解除
   - お気に入り一覧画面（お気に入り商品の閲覧、直接カート追加機能）

## 3. データモデル（ER仕様）

### ① User (ユーザー)
- `id`: 主キー
- `username`: ユーザー名 (一意)
- `password`: ハッシュ化パスワード
- `email`: メールアドレス
- `first_name`: 名
- `last_name`: 姓
- `is_staff`: 管理者フラグ (Boolean)
- `created_at`: 登録日時

### ② Tag (タグ)
- `id`: 主キー
- `name`: タグ名 (例: レディース, メンズ, バッグ, アウター, ワンピース, シューズ, ヴィンテージ等)
- `slug`: URL用識別子 (英数字)
- `color`: Bootstrapカラー指定 (`primary`, `success`, `danger`, `warning`, `info`, `dark`, `secondary`)

### ③ Product (商品)
- `id`: 主キー
- `name`: 商品名 (VARCHAR 200)
- `description`: 商品説明 (TEXT)
- `price`: 販売価格 (整数の日本円)
- `stock`: 在庫数 (整数、初期値 10)
- `image`: 画像ファイルパス (VARCHAR / 未指定可)
- `is_active`: 公開状態 (Boolean, 初期値 True)
- `created_at`: 登録日時
- `updated_at`: 更新日時
- **リレーション**: `tags` (Tag と多対多: `product_tags` 中間テーブル)

### ④ Order (注文)
- `id`: 主キー
- `user_id`: 外部キー (User.id, 未ログイン購入を許容する場合は Nullable)
- `order_number`: 注文番号 (一意, 例: `ORD-ABC12345`)
- `full_name`: 氏名
- `postal_code`: 郵便番号
- `address`: 配送先住所
- `phone_number`: 電話番号
- `email`: メールアドレス
- `payment_method`: 支払方法 (`credit_card`, `bank_transfer`, `cod`, `convenience`)
- `total_price`: 注文合計金額
- `status`: 注文ステータス (`pending`, `processing`, `shipped`, `completed`, `cancelled`)
- `created_at`: 注文日時

### ⑤ OrderItem (注文明細)
- `id`: 主キー
- `order_id`: 外部キー (Order.id, CASCADE削除)
- `product_id`: 外部キー (Product.id, SET NULL)
- `product_name`: 購入時の商品名 (商品削除時も記録を保持)
- `price`: 購入時の単価
- `quantity`: 購入数量

### ⑥ Favorite (お気に入り)
- `id`: 主キー
- `user_id`: 外部キー (User.id)
- `product_id`: 外部キー (Product.id)
- `created_at`: 登録日時
- **制約**: `(user_id, product_id)` のユニーク制約

## 4. UI/デザイン仕様 (Bootstrap 5)

- **ヘッダー (Navbar)**
  - ブランドロゴ（`exShop` + アイコン `bi-bag-heart-fill`）
  - キーワード検索ボックス
  - タグドロップダウンメニュー（バッジ付き）
  - 「商品登録」ボタン
  - お気に入りアイコン（バッジで件数表示）
  - カートアイコン（バッジで点数表示）
  - ユーザーメニュー（マイページ、購入履歴、管理者メニュー、ログイン/ログアウト）
- **トースト / フラッシュメッセージ**
  - 操作時（カート追加、お気に入り登録、注文完了、エラー）に Bootstrap の Alert を画面上部に表示。
- **商品カード**
  - 1:1 正方形アスペクト比で画像を中央配置 (`object-fit: cover`)
  - 右上にお気に入りトグルボタン（ハートアイコン）
  - タグ一覧バッジ
  - 税込価格、在庫状況バッジ
  - 「カートに追加」クイックボタン

## 5. AI生成用プロンプトテンプレート

### 【プロンプト①: Flask版の作成を指示する場合】

```markdown
以下の「exShop ECサイト演習プログラム仕様書」に基づき、Pythonの軽量Webフレームワーク「Flask」を使用した完全なWebアプリケーションを作成してください。

【要件】
1. フレームワーク: Flask, Flask-SQLAlchemy, Flask-Login
2. データベース: SQLite
3. テンプレートエンジン: Jinja2 + Bootstrap 5.3 CDN
4. 実装機能:
   - 会員登録・ログイン・ログアウト・マイページ
   - 商品一覧、キーワード検索、タグ絞り込み、ソート、ページネーション
   - 商品詳細（関連商品レコメンド含む）
   - 画像未登録時の「no-image.png」フォールバック
   - セッションを使用したショッピングカート（追加・数量変更・削除・合計計算）
   - チェックアウト（配送先入力、トランザクションによる注文・注文明細保存、在庫減算）
   - 購入履歴一覧および明細詳細
   - お気に入り機能（追加・解除トグル、お気に入り一覧）
   - 商品登録・編集機能（管理者用）
5. 初期データ投入スクリプト (seed.py):
   - 管理者 (admin / admin123) および一般ユーザー (student / student123)
   - サンプルタグ10件、サンプル商品30件程度を自動生成するコードを含めてください。
```

### 【プロンプト②: Java Servlet / JSP版の作成を指示する場合】

```markdown
以下の「exShop ECサイト演習プログラム仕様書」に基づき、Javaの「Jakarta EE (Servlet 6.0 / JSP / JSTL)」を使用した完全なMVCモデルのECサイトアプリケーションを作成してください。

【要件】
1. 構成: Servlet (Controller) + JavaBean (Model / DTO) + DAO + JSP (View)
2. データベース: H2 Database または MySQL / PostgreSQL (JDBC接続)
3. フロントエンド: Bootstrap 5.3 CDN + JSTL (<c:forEach>, <c:if> 等)
4. ビルドツール: Maven (pom.xml) または Gradle
5. 実装機能:
   - フィルターによる文字コード(UTF-8)制御
   - HttpSession を利用したユーザー認証（ログイン・ログアウト）とカート管理
   - 商品一覧、キーワード検索、タグ絞り込み、ソート
   - 商品詳細・関連商品表示
   - 画像未登録時の no-image.png フォールバック
   - カート機能（Itemのリストをセッション保持、合計金額計算）
   - 注文処理（DB接続のトランザクション管理: setAutoCommit(false) による注文と注文明細の保存、在庫数更新）
   - 購入履歴表示
   - お気に入り機能
6. 初期データ投入用 SQL (schema.sql / data.sql) を添付してください。
```
